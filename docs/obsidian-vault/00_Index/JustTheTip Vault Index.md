## Current Baseline

PCB1 is a 50 mm x 50 mm STM32 controller board with USB-C, power conversion, debug serial, and five FFC sensor ports. PCB2 is a compact TMF8829 sensor board with local decoupling, optical keepouts, one FFC connector, and two mounting holes.
